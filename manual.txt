# CyberGuard Academy — Educational App Manual & Play Store Publication Guide

## 1. About This App

CyberGuard Academy is an **offline educational app** for learning cybersecurity
fundamentals. It teaches concepts — not protection. It does **not** scan,
monitor, clean, or protect your device.

- **App name:** CyberGuard Academy
- **Package:** `com.abinet.cyberguard`
- **Version:** 1.0.0 (versionCode 1)
- **Developer:** Abinet Endale — endaleabinet67@gmail.com
- **Min SDK:** 26 (Android 8.0)
- **Target SDK:** 36 (Android 16) — required by Google Play for new apps
- **Permissions requested:** NONE
- **Network access:** NONE — the app works entirely offline
- **Data collected:** NONE

> **Mandatory disclaimer** (must appear in the Play Store listing and in the
> app's onboarding screen):
> *CyberGuard Academy is an educational app. It does not scan or protect your
> device. Any analysis shown is for learning purposes only.*

## 2. Features

| Feature | Description |
|---|---|
| **7 lessons** | Malware 101, Banking Trojans, Ransomware, Phishing, APK Anatomy, Dangerous Permissions, and Pattern Rules. Each lesson is a short, plain-language explanation aimed at a curious beginner. |
| **APK Analysis Lab** | Pick any `.apk` file from storage. The app runs simple heuristics on the file and explains what it detected in educational terms — plus why a "match" here is not proof of malice and a "clean" result is not proof of safety. |
| **Pattern Rule Playground** | Shows 7 simplified, YARA-inspired rules. Pick a rule, run it against your own text sample, see how substring matching works — and how easily short strings cause false positives. |
| **Phishing Quiz** | 5 real-world-style scenarios (fake PayPal email, delivery SMS, family-emergency scam, IT-department phishing, etc.). After each answer, a plain-language explanation of why it was suspicious or safe. |
| **Permissions Explainer** | Static reference cards for 9 key Android permissions across three categories (NORMAL, DANGEROUS, SPECIAL), with guidance on when to grant each. |
| **Threat Encyclopedia** | 6 threat-family cards — Banking Trojan, Spyware/Stalkerware, Ransomware, Dropper, Adware/Clicker, Phishing/Smishing — each with indicators and defensive guidance. |
| **Progress tracking** | Completed lessons and quiz scores persist between sessions using SharedPreferences. Reset option available in Settings. |
| **No ads, no analytics, no network, no accounts.** |

## 3. Installation & First Run

1. Install from Google Play (or install the debug APK directly during testing).
2. Launch the app. The **onboarding screen** appears once, showing the
   disclaimer. Tap **Start Learning**.
3. From then on, the app opens directly to the **dashboard**.

There is no permission flow, no login, and no setup step.

## 4. User Interface Guide

### 4.1 Onboarding Screen
- Shows the app title, a one-line description, a highlighted disclaimer card,
  a feature list, and a single **Start Learning** button.
- Shown only on first launch. A boolean in `SharedPreferences` (`onboarding_done`)
  suppresses it thereafter.

### 4.2 Dashboard
- Header: `EDUCATIONAL` tag (rotated), `CYBERGUARD ACADEMY` title, `LAB READY ·
  LEARNING MODE` subtitle.
- `N / 7 LESSONS COMPLETED` — live progress counter.
- **ANALYZE A SAMPLE APK** — opens the system file picker for `.apk` files.
- **Phishing Quiz** and **YARA Playground** buttons (row 1).
- **Permissions** and **Encyclopedia** buttons (row 2).
- Scrolling lesson list — each row shows title, subtitle, and `✓ COMPLETED` or
  `○ NOT STARTED`. Tap to open the lesson.
- **Settings** button at the bottom.

### 4.3 Lesson Detail
- Title, subtitle, and body text (five paragraphs per lesson).
- **Mark as Completed** button — marks the lesson complete and returns to the
  dashboard.

### 4.4 APK Analysis Lab
- Opens the system file picker filtered to `application/vnd.android.package-archive`.
- Copies the selected file to a temp directory, runs the heuristic engine
  (`MalwareScanner`), and displays results in a dialog.
- Every result includes the explicit note: *"These are educational heuristics.
  A 'match' here is not proof of malice, and a 'clean' result is not proof of
  safety."*
- No install, no delete, no "blocked" messaging.

### 4.5 Phishing Quiz
- 5 questions, one per screen. Each shows a scenario, up to 4 answer buttons,
  and after answering, a feedback panel with the explanation.
- Buttons turn green (correct) or red (selected wrong) after answering.
- Final dialog shows score with "Back to Dashboard" and "Try Again" options.

### 4.6 YARA Playground
- Rule dropdown (7 rules from `res/raw/yara_rules.txt`).
- Rule detail panel showing name, condition (`any`/`all`), and strings.
- Editable sample text — prefilled with the rule's own strings.
- **Run Rule** button — reports MATCH or no-match.
- Footer text explains that the real YARA language is far more expressive than
  the simplified rules used here.

### 4.7 Permissions Explainer
- 9 cards, each with permission name, a color-coded level badge (green NORMAL,
  amber DANGEROUS, red SPECIAL), and a plain-language description.
- Fully static — no device inspection.

### 4.8 Encyclopedia
- 6 threat-family cards. Tap a card to open a dialog with full description,
  indicators (what to look for), and defense (how to protect against it).

### 4.9 Settings & About
- **Reset Learning Progress** — confirm dialog, then clears all stored progress.
- **Contact the Developer** — opens the mail app addressed to
  `endaleabinet67@gmail.com` with subject "CyberGuard Academy feedback".
- **Privacy Policy** — in-app dialog with the full text (see §6).
- **About Developer** section — displays *Abinet Endale* and
  `endaleabinet67@gmail.com`.
- **App version** — read from `BuildConfig.VERSION_NAME`.

## 5. Permissions

**CyberGuard Academy requests zero permissions.** The manifest contains no
`<uses-permission>` entries, no `<queries>` block, and no exported components
except the launcher activity.

The APK Analysis Lab reads a file the user explicitly selects through the
system file picker — this uses the Storage Access Framework and does not
require any storage permission.
